🃏 Blackjack Game (Python)

A simple command-line Blackjack game built with Python.
This project was created as part of a programming bootcamp inspired by Angela Yu's Python course.

📌 Features
🎴 Random card dealing
🧠 Automatic score calculation
♠️ Blackjack detection
🤖 Computer opponent logic (draws until 17)
🔁 Replay option
🚀 How to Run
Make sure you have Python installed (Python 3.x)
Clone this repository:
git clone https://github.com/your-username/blackjack-python.git
Navigate into the project folder:
cd blackjack-python
Run the game:
python main.py
🎮 How to Play
You start with 2 cards.
Type 'y' to draw another card.
Type 'n' to pass.
The goal is to get as close to 21 as possible without going over.
Special Rules:
Ace (11) can become 1 if needed.
Blackjack = Ace + 10-value card (automatic win).
